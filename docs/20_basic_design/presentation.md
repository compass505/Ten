#### 2.1.1 取り込みの手順

1. `mother-runtime.fbx` を `unity/Assets/Art/Mother/` に置く（Rig は Generic、Loop Time は上表のとおり）
2. Animator Controller を作る。**層は Body / Hand の 2 つ**、パラメータは `int Body`・`int Hand`・`int Reaching`・`bool Sniff`
3. `RoomRig.BuildMother()` のプリミティブを、読み込んだモデルに置き換える。**`AnimateBody` / `AnimateHand` の中身は Animator へのパラメータ設定だけにする**
4. **視線の判定用の代理物（`ParentFace` / `ParentHand` / `Window`）は残す。**`Renderer.forceRenderingOff = true` にして見えなくし、位置と大きさは今のまま（handoff.md H-07。TC-122 はこの 3 つの箱で測っている）
5. 顔の中心・手の静止位置が代理物の中に入るように、モデルの置き場を合わせる

#### 2.1.2 `Carry`（盲目区間）

- 目を閉じているので**母の体は描かない。**使うのは `Carry` に入っているカメラ（Ten の目）の移動曲線だけ
- 基準長 2.0 秒の曲線を、**`SettleTicks` の長さに伸縮して** `CarryTick / SettleTicks` で引く
- 引いた位置を `RoomRig.SetCarried` の窓の明かりのずれに写す。**成否で呼び分けない**（MOD-Present PR-2 / TC-171）

### 4.4 共有する文字列

```
Ten 9月13日
今夜は通算4回のうち、3回目がいちばんよかった。朝まで持ちこたえられて、起こせたのは2回（はじめの一撃が効いた、窓が白んできた）。（盤面 v1）
［どっぷり 背中スイッチ選手権］今夜は、布団に置くたびに…
```

- 2 行目は `Result.Compose`（REQ-026 / 028 / 031 / 040 / 054）。**その日の最高成績の 1 回分**（REQ-025）
- 3 行目は診断（REQ-062）。濃さの修飾語は `Result.Title`（G-03）
- 1 行目の日付は**盤面の答えではない**（夫婦で同じ日を遊んだと分かるため）→ 6 節 PRE-02

## 5. チュートリアル（`SCR-Tutorial`）

**1 回の夜で 3 段を通す**（MOD-Tutorial TUT-01 を「1 回で通す」に決めた。「一晩」の形を先に体験できる）。

| 段 | 画面上部の一言 | 完了 |
| --- | --- | --- |
| 1/3 起こす | `画面の下を押すと声が出る。長く押すほど強い。上をドラッグして首を振り、お母さんの顔を見ながら起こしきる。` → 起きたら `起きた。お母さんは部屋を出ていった。静かにしていると、また戻ってきて眠る。` | 1 点取る |
| 2/3 元気 | `泣き続けると元気が減る。減るほど視界のゆれが小さくなり、尽きると端が暗くなる。一度使い切ってみる。` | 元気 0 |
| 3/3 寝たふり | `右下を押して目を閉じる。何も見えなくなるが、そのまま待つ。` → 閉眼中 `抱き上げられている…かもしれない。置かれたと思ったら、右下で目を開けて、すぐ泣く。` → 開眼して猶予中 `いま！ 左下を押して泣く。` | 寝たふりが通り、**着地後の猶予が終わるまで**（泣くところまで体験させる） |
| 完了 | `これで全部。起こす・元気・寝たふり。あとは毎日かわる盤面で、何回起こせるか。` | `はじめる` → `SCR-Home` |

- **押し場所の名前（`泣く` `ぐずる` `ばたつく` `目を閉じる`）を、チュートリアルの間だけ画面下に出す。**
  夜の本編には出さない（REQ-044）→ 6 節 PRE-01
- 夜が終わっても段が残っていれば、**同じ段から新しい夜でやり直す**（MOD-Tutorial のエラー時）。`もう一度` と 2 秒出す
- プレイ回数に数えない。進行中のプレイとして保存しない（中断されたら次の起動でチュートリアルの最初から）

## 6. 本人に確かめたいこと（**仮に決めて動かしている**）

**どれも後戻りは 1 日以内**なので ADR にしていない。違っていたら、ここと実装を直す。
