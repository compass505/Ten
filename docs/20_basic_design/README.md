# 基本設計

> フェーズ 2。要件が確定するまで着手しない。

## 置くもの

| ファイル | 内容 |
| --- | --- |
| `architecture.md` | モジュール分割（`MOD-xxx`）と依存方向。依存は一方向に保つ |
| `screens.md` | 画面 / 状態の遷移。遷移が閉じている（行き止まりがない）こと |
| `data_model.md` | 扱うデータの構造と、永続化するもの / しないものの線引き |

## DoD

- 全 Must 要件が、いずれかの `MOD-xxx` に割り当てられている
- どのモジュールにも割り当てられない要件が残っていない
- 依存方向に循環がない
