## 1. これは何か

**育児の大変さを再演するゲームではない。反転させて笑うためのもの**
（[ADR-0006](../10_requirements/decisions/ADR-0006-concept.md)）。

- プレイヤーは**寝かしつけられる側**になる。夜通し起こしてくる側の理屈が分かる
- 笑いの質は**あるあるの共有**。皮肉でも自虐でもない。
  「背中スイッチ」「置いた瞬間に泣く」を、やる側からやってみる遊び
- **親を悪者にしない。**親は疲れていて、でも毎回ちゃんと来る。
  赤ちゃんは悪意なく、ただ起きていてほしいだけ
- 遊ぶのは**寝かしつけた直後の本人**。負けても嫌な気持ちにならないこと

> **用語の注意**: このプロジェクトで「窓」は**寝室の壁にある実物の窓**だけを指す。
> タイミングの猶予時間を window と呼ばない（「寝入りばな」「猶予」と書く）。

## 2. 世界

| | |
| --- | --- |
| いつ | 一晩（ゲーム内 21:00〜6:00）。実時間 4 分 30 秒 |
| どこ | 日本の集合住宅の寝室 1 部屋。**床に敷いた布団**。ベビーベッドではない |
| 赤ちゃん | **Ten。生後 1 か月、男児。**仰向けで動けない。首も据わっていない |
| 親 | 30 前後。**名前も性別も明示しない。**プレイヤーが配偶者を重ねられるようにする |
| 季節・天候 | 決めない。窓の外は時刻だけを表す |

- **親の顔立ちは特定の誰かに寄せない。**夫婦のどちらが遊んでも成立させる
- 部屋に生活感を置く（畳んだ服、哺乳瓶、ベビーモニター）が、
  **触れない。**操作対象は 4 つの行動と首振りだけ（REQ-003 / 005）

## 3. 寝室の寸法とカメラ

| | 値 |
| --- | --- |
| 部屋 | 幅 4.4 m × 高さ 2.7 m × 奥行 5.2 m |
| カメラ（Ten の目） | 床から **0.28 m**。**真上（天井）を向く**のが初期姿勢 |
| 天井 | 高さ 2.5 m。**板目を入れる**（首を振ったときに動きが分かるため） |
| 布団 | 床面。Ten は部屋の中央やや窓寄り |

**座標系**: Ten の頭が原点、足が +Z、天井が +Y、窓の側が +X。
首を振るのは Z 軸まわり（左右）と X 軸まわり（頭側 / 足側）。

### 首の可動範囲（REQ-002）

| 軸 | 範囲 |
| --- | --- |
| 左右 | **±55°** |
| 上下 | **−15°〜+30°**（+ が天井の奥側） |

### 視線の 3 対象（[screens.md](screens.md) 4.2.1 / D-11）

**3 つは同時に視界へ入らない。**この配置が「見ることが選択になる」の根拠。

| 対象 | 位置 | 見える首の角度 | 分かること |
| --- | --- | --- | --- |
| 窓 | (+2.19, 1.50, −0.30) 右の壁。1.7 × 1.3 m | **−55°〜−41°** | 残り時間 |
| 親の顔 | (−0.30, 1.15, 0.15) 左側。半径 0.24 m | **−1°〜39°** | 覚醒度 |
| 親の手 | 静止時 (−0.50, 0.73, −0.18) | **29°〜55°** | 次に来る対処 |
| 天井の照明 | (+0.75, 2.34, −0.75) | — | （情報を持たない） |

- **初期視線は天井**＝何も分からない状態から始まる
- 窓と親の手は約 **95° 離れている**。首の可動範囲（110°）ぎりぎりで、同時には見られない

## 4. 親の見え方（数値を出さずに状態を伝える）

[ADR-0010](../10_requirements/decisions/ADR-0010-no-numbers.md)。
**明度差だけに依存しない。**輪郭・姿勢・動きの周期で冗長化する（REQ-044）。

### 4.1 覚醒度（4 段階。境界は [balance.md](balance.md) 2 節）

| 段階 | まぶた | 口 | 呼吸（動きの周期） | 首・姿勢 |
| --- | --- | --- | --- | --- |
| **0〜24 熟睡** | 完全に閉じる | **開く** | 遅く大きい（約 4 秒周期） | 上を向いて脱力。こちらを向いていない |
| 25〜59 浅い | 閉じているが眉が動く | 閉じる | 普通（約 3 秒） | わずかにこちら向き |
| 60〜89 半分起きる | **薄く開く** | 閉じる | 速く浅い（約 2 秒） | こちらを見ようとする |
| **90〜100 覚醒** | **開く** | 閉じる | 不規則 | **上体を起こす** |

**端点は正確に分かる**（REQ-045）: 覚醒度 100 に達した瞬間、**親はベッドを出て視界から消える**。

### 4.2 寝入りばな（[ADR-0015](../10_requirements/decisions/ADR-0015-input-intensity-and-timing.md) **承認待ち**）

| | 見え方 |
| --- | --- |
| **予兆**（4.5 秒間） | **呼吸が深くなる。**胸と頭の上下が大きく、周期が遅くなる |
| **寝入りばな本体**（1.8 秒間） | **かくっと力が抜ける。**頭が沈み、輪郭がわずかに潰れる |

**顔を見ていないと分からない。**これが首を振る具体的な見返りになっている。

### 4.3 山札の残量（3 段階。手つきで伝える）

| 段階 | 手 | 反応の速さ | 部屋 |
| --- | --- | --- | --- |
| 序盤（6 枚以上） | トントンのリズムが規則正しい | すぐ来る | 暗いまま |
| 中盤（3〜5 枚） | リズムが乱れる、雑になる | 一拍遅れる | 暗いまま |
| **終盤（1〜2 枚）** | **手が途中で止まる** | **明らかに遅い**（REQ-046） | **電気をつけっぱなしにする** |

**端点**: 山札 0 で夜が終わる（親が寝るのを諦めてリビングへ行く。REQ-042）。

### 4.4 親の状態ごとの姿

| 状態 | 姿 |
| --- | --- |
| `ST-P-Sleep` | 横向きで寝ている。4.1 の段階に従う |
| `ST-P-Care` | 手が伸びてくる。対処ごとに動きが違う（下記 5 節） |
| `ST-P-Settle` | 抱き上げて布団に置く。**この間 Ten は目を閉じているので見えない** |
| `ST-P-Grace` | 置いた直後。まだ手が離れていない |
| `ST-P-Up` | **視界から消える。**部屋が空になり、天井の電気が点く。**顔も手も読めない** |

## 5. 親の 4 つの対処（REQ-013）

**どれも赤ちゃんの状態を 1 つ改善し、1 つ悪化させる。**動きで見分けられること。

| 対処 | 動き | 見た目で分かる「損」 |
| --- | --- | --- |
| トントン | 胸を一定のリズムで叩く | 手が視界の中央を塞ぐ |
| ミルク | 哺乳瓶が視界に入り、顔の前を占める | **視界がほぼ塞がる**（何もできない） |
| 抱っこ | 抱き上げられ、**視点が上がる** | 部屋の見え方が変わり、天井が遠くなる |
| オムツ替え | 下半身側で手が動く。親が大きく動く | 終わると親が布団に沈み込む（寝直す） |

## 6. その夜の出来事（REQ-043 / 055。1 夜 3〜5 件）

| 出来事 | 見え方 |
| --- | --- |
| オムツが汚れた | 親が鼻をひくつかせる。山札にオムツ替えが 1 枚増える |
| **もう一人の親が起きてきた** | **反対側（+X 寄り）に 2 人目が現れ、その夜ずっといる。**山札が 2 枚増える |
| 親のスマホが鳴った | **枕元が一瞬だけ光る。**暗所なので明るさの変化が最も強い刺激になる |
| 親が寝返りを打った | **顔が向こうを向く。**約 10 秒、覚醒度が読めない |
| おなかが空いた | 視界の周辺が沈む。約 20 秒、元気が減り続ける |

## 7. 光と色

**NFR-007: 全画面について、画素の相対輝度の平均が 0.1 以下。**

| | |
| --- | --- |
| 基本 | 窓からの月明かりだけ。青灰色に寄せる |
| 窓 | 21:00 濃紺 → 4:00 過ぎから白み始める → 6:00 直前が最も明るい（**端点。正確に分かる**） |
| 天井の照明 | 通常は消灯。**親が起きている間**と**山札が残り 3 枚以下**で点灯（暖色） |
| 彩度 | 全体に低く。**暖色は親の肌と照明だけ**に使い、それが目を引くようにする |

**暗所で見るので、明るさの変化そのものが強い演出になる。**
スマホが光る・電気が点くは、それだけで十分に「事件」として伝わる。

## 8. 赤ちゃん（プレイヤー）の表現

**姿は見えない**（一人称・移動しない。ADR-0007）。伝えるのは視界の側。

| 状態 | 見え方 |
| --- | --- |
| 呼吸 | 視界が常にゆっくり上下する。**元気が少ないほど周期が遅く、振れ幅が小さい** |
| 覚醒行動を溜めている | 視界の揺れが大きくなる（[ISS-19](../10_requirements/open_issues.md) の長押し） |
| 行動の実行 | 画面が揺れる。泣くほど大きい |
| 目を閉じている | **完全に黒。**閉じる直前に窓を向いていた場合だけ、その方向に明かりが不透明な色で残る（D-12）。**抱き上げられると動く。ただし寝たふりに失敗したときも同等に動く**（[ADR-0017](../10_requirements/decisions/ADR-0017-parent-moves-on-failure.md)。動きが成否の通知にならないことが REQ-016 の成立条件） |
| 元気が尽きた | 視界の周辺が沈む |

## 9. やらないこと（見た目）

| やらない | 理由 |
| --- | --- |
| 数値・ゲージ・アイコン | REQ-044 / [ADR-0010](../10_requirements/decisions/ADR-0010-no-numbers.md) |
| 音・BGM・バイブレーション | [scope.md](../10_requirements/scope.md)。無音が前提 |
| 明るい画面・白い UI | NFR-007。暗所で見る |
| 親の移動アニメーション（歩く等） | ADR-0007。必要なのは**手と顔だけ**。`ST-P-Up` は視界外へのフェードで済ませる |
| 赤ちゃんの体・手足の描画 | 一人称。視界の揺れで表す |
| 部屋の外・他の部屋 | 寝室 1 部屋のみ |
| 画面の向きの切り替え | scope.md。対象端末 1 台に固定 |
