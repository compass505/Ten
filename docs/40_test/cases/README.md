# テストケース

`TC-001-短い説明.md` の形で 1 ケース 1 ファイル、または観点ごとにまとめて置く。
書式は [../../_templates/test_case.md](../../_templates/test_case.md)。

規約は [../../00_process/test_first.md](../../00_process/test_first.md)。

- 期待値は数値・状態・回数で書く。「正しく動く」は不可
- 期待値を具体的に書けないケースは、**要件が曖昧である証拠**。
  テストを無理に書かずに要件へ差し戻す
- 承認テスト（出力を丸ごと保存して比較）は使わない
