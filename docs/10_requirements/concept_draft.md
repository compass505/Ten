# コンセプト草案

> 記載はヒアリングで実際に出たことのみ。推測で埋めた欄は「仮置き」、
> 聞けていない欄は「未確認」と明記する。確定したら requirements.md に ID 付きで落とす。

## 一行で言うと

**（仮置き）寝かしつけ後、片手だけが空いている数分に、夫婦それぞれが遊んで、
結果を見せ合って笑うためのゲーム。通信もアカウントも持たない。**

> 「仮置き」の理由：方向（C'-1 共感ゲーム）は 2026-09-01 に確定したが、
> **ゲームの中身が未定**。「問題を解く」形式はユーザー判断で却下済み。

## 誰の何を解決するか

| 項目 | 内容 |
| --- | --- |
| 想定ユーザー | 30 歳男性。1 か月前に第一子（男児・Ten）が生まれた父親と、その配偶者。端末は Android スマートフォン。開発者本人ではなく、直接ヒアリングできる身近な人物 |
| 困りごと | **本人が挙げた困りごと（P-1〜P-5）は、いずれも解かない**。下の「方向転換の記録」を参照 |
| 既存の代替手段 | 育児の共感は SNS の育児漫画が満たしている。ただし形式は一方向に読む漫画で、夫婦 2 人が関与して笑う形ではない（→ [research/hook_options.md](research/hook_options.md) 2 節） |
| それでも作る理由 | **開発者の仮説**。2〜3 週間で実際に完成して手渡せるのがこの方向だけであり、未完成のアプリは誰の困りごとも解かないため |

## 方向転換の記録（2026-09-01）

P-5（情報の後出し）を対象に定めたが、調査で次が判明した。

1. パパninaru が「父親向けに月齢連動で毎日配信」を既に実装し 30 万人規模に届いている
2. 情報を出すだけのアプリは状態も順序も持たず、[ADR-0002](decisions/ADR-0002-test-harness.md) の
   「この決定が崩れる条件」に該当する
3. 記録連動はぴよログが、共感コンテンツは育児漫画が既に埋めている

ユーザー判断により、**困りごとへの忠実さより「2〜3 週間で完成して手渡せること」を優先**し、
夫婦で笑うための共感ゲームに切り替えた。**根拠が本人の困りごとから開発者の仮説に
変わったことを、自覚したうえでの選択である。**

追加のユーザー判断（2026-09-01）：**「問題を解く」形式は却下。**
正解のあるゲームは面白みに欠けるため。ゲームにする以上、面白さが命になる。

## 利用場面（確認済み）

- 寝かしつけたあと、赤ちゃんを抱いたままソファーに寝ている状態
- **片手だけが空いている**

> ここから導かれる制約（片手操作・暗所・無音・赤ちゃんを起こせない・中断される）は
> **本人に未確認**。要件化する前に確かめる。

> **この場面自体を強みとして使う**（ユーザー指摘 2026-09-01）。
> 寝かしつけ後の「片手が空いていて、他にやることが無く、毎日必ず訪れる時間」は、
> 情報を届ける枠として都合が良い。制約としてだけでなく、設計上の資産として扱う。
> どう活かすかは未検討。

## 最小で成立する形（仮置き）

夫婦がそれぞれ片手で遊び、**結果を見せ合って笑える**こと。
共有は既存の手段（LINE 等）に貼るだけで成立させ、通信・アカウント・サーバーを持たない
（Wordle 方式 → [research/game_direction.md](research/game_direction.md) 2 節）。

**ゲームの中身は未定。** ここが決まらないと要件を書けない。

## 動作環境の想定

- Android スマートフォン（本人の端末）。スマホ利用が前提
- 開発規模の想定：**2〜3 週間でひと通り**（複数画面・データ保存を含み、人に見せられる状態まで）
- 提供形態（ネイティブ / PWA / Web）は未定 → ADR-0001

## 検討したが採らなかった案

| 案 | 見送った理由 |
| --- | --- |
| 撮り逃しをなくす（常時バッファ録画→遡って保存） | 共有は みてね で足りている。カメラ常駐・電池・権限・容量が重く、2〜3 週間に収まらない |
| 泣き声から理由を推定する | 学習データが手元に無く精度が出ない。健康領域のリスク。ADR-0002 の決定論ハーネスと相性が悪い |
| ミルク量・睡眠の育児記録 | 既存の育児記録アプリが多数あり差別化が要る。「適切か」の判定は医療判断に踏み込む |
| 「一番きつい困りごと」から選ぶ | 5 つとも大変で優劣を付けられない。開発で取り組める範囲から選ぶ方針に変更（ユーザー判断 2026-09-01） |

## 未確認リスト

- **本人が寝かしつけ後に実際にゲームをするか**（東大の研究では寝かしつけ中のスマホ利用は
  10% 強にとどまる → [research/game_direction.md](research/game_direction.md) 1 節）
- **本人と配偶者に「笑いたい」「共感したい」欲求が実在するか**。ヒアリングで一度も出ていない
- 配偶者の端末（iOS か Android か）。夫婦で遊ぶ以上これは要件に効く

- 利用場面から導いた制約（片手・暗所・無音・中断）が実際に効いているか
- 「もっと早く知りたかった」の**実例**。具体的に何を、いつ知りたかったのか（最重要）
- セミナー / SNS の何が拾いきれないのか（量なのか、順序なのか、自分に関係あるか判別できないのか）
- 育児記録アプリ・育児情報アプリの利用有無、一度使ってやめたものとその理由
- 妻との役割分担・情報共有のしかた
- 通知を許容するか（先回りする以上、届け方が要る）
