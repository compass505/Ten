# 調査: 「わざわざ作る理由」になる一要素は何か

**この調査で何を決めたいのか**: 情報を絞って出すだけ（existing_apps.md 案 A）では
既存に対する足し算が無い。何を一要素加えれば作る理由になるか。

調査日: 2026-09-01 / → ADR 候補 / 対象 ISS-01
発端: ユーザー指摘 2026-09-01「ただの A では良さがあまりない。動画をつける、
記録に連動して情報が出る、あるいは片手でできて夫婦で笑えるゲームにする、
のような一要素が要る」

## 1. 記録連動は、ぴよログが既に踏んでいる

ぴよログは無料の育児記録アプリで、記録・共有・アドバイスを一通り持つ。

- 記録項目：母乳 / ミルク / 搾母乳 / 離乳食 / おやつ / うんち / おしっこ / 睡眠 /
  体温 / 身長 / 体重 / お風呂 / さんぽ / せき / 発疹 / 嘔吐 / けが / くすり / 病院 /
  自由記述 / 写真つき育児日記
- **家族全員のリアルタイム共有**をサポート。パパ・ママだけでなく祖父母とも同期できる
- **記録に応じた情報提示も持つ**。食材ごとに注意点や与え方のアドバイスが見られる

> 出典: [育児記録アプリ ぴよログ](https://www.piyolog.com/)（2026-09-01 アクセス）
> 出典: [ぴよログ - 育児記録アプリ](https://apps.apple.com/jp/app/%E3%81%B4%E3%82%88%E3%83%AD%E3%82%B0-%E8%82%B2%E5%85%90%E8%A8%98%E9%8C%B2/id6773601450)（App Store、2026-09-01 アクセス）

つまり「記録すると、その時にぴったりの情報が出る」は、**離乳食という領域では既に実装済み**。
記録の主戦場（項目数・家族共有・継続率）で個人開発が真っ向から勝つのは難しい。

## 2. 育児の共感コンテンツは巨大な既存ジャンル。ただし形式は「読む漫画」

SNS 発の育児漫画は確立したジャンルで、あるある・共感・笑い・感動・お役立ちといった
軸で多数まとめられている。パパ目線の作品もある。育児のストレスを笑いに変える
エンターテインメントとして読まれている。

> 出典: [厳選！SNSで人気の育児漫画まとめ【あるある・共感・笑い・感動・お役立ち】](https://beauty.oricon.co.jp/special/100741/)（eltha、2026-09-01 アクセス）
> 出典: [現役ママに人気の子育て漫画10選](https://hugkum.sho.jp/7361)（HugKum、2026-09-01 アクセス）

**「共感」は既に満たされているが、その形式は一方向に読む漫画である。**
夫婦二人が同じものに関与して笑う、という形は、この調査の範囲では見つからなかった。

## 3. 片手・縦持ちで遊べるゲームは確立したカテゴリ

縦持ちのまま片手で遊べるゲームは、まとめ記事が成立する程度に数がある。
満員電車や片手が塞がっている状況で扱いやすい点が特徴として挙げられている。
放置系（AFK アリーナ、プリケツにゃー！等）、パズル・マージ系（ツムツム等）が挙がる。

> 出典: [【縦持ち・縦画面】片手でできるおすすめ無料スマホゲームアプリランキング32選](https://takataro.com/app-tatemoti/)（2026-09-01 アクセス）
> 出典: [縦持ちで遊べるスマホゲームおすすめ7選【片手でも快適】](https://games.appmatch.jp/61806202-43782/)（2026-09-01 アクセス）

### この節の証拠は弱い

1〜3 節はいずれも比較記事・まとめ記事に依存しており、
**「育児当事者向けの、夫婦で遊ぶゲーム」が存在しないことの証明にはなっていない。**
無いのではなく、この探し方では見つからなかった、が正確な状態。

## 4. ADR-0002 との相性が、案によって正反対になる

[ADR-0002](../decisions/ADR-0002-test-harness.md) の「この決定が崩れる条件」に、
次の一文がある。

> 作るものが「状態も並行性も順序もほぼ持たない」と要件確定時に判明したとき
> （その場合は A で足りる）

**情報を出すだけのアプリは、まさにこの条件に当たる。** 状態は「既読かどうか」程度で、
並行性も順序も無い。シード注入型の決定論ハーネスは過剰になり、
ADR-0002 を覆すか、ハーネスが空回りするかのどちらかになる。

**ゲームは逆で、状態・順序・並行性を全て持つ。** 入力列とシードから同じ結果が出ることを
検証する ADR-0002 のハーネスは、ゲームに対して最も素直に機能する。

これは好みの問題ではなく、**既に Accepted になっている決定との整合の問題**である。

## この調査から導く結論（→ ADR 候補 / コンセプト差し戻し）

**「一要素を足す」ではなく、「何を作るかの作り直し」として扱うべきである。**
記録連動もゲームも、[scope.md](../scope.md) の「やらない」（育児記録 / 夫婦間の共有）を
書き換える。足し算ではなく前提の変更なので、コンセプトに差し戻す。

### 選択肢

| # | 案 | 利点 | 欠点 |
| --- | --- | --- | --- |
| A' | 情報 + 動画 | 見た目のインパクト。事前生成なら $135 程度で足せる | 中身の薄さを演出で埋めることになる。寝かしつけ中は無音制約で強みが半減（→ [ai_video.md](ai_video.md) 5 節）。ADR-0002 の空回りは解消しない |
| B' | 情報 + 記録連動 | 「その時にぴったり」は文脈が効く。記録が情報の入力になる | ぴよログが記録・家族共有・食材アドバイスまで実装済み。記録先が増えると夫婦で二重管理になる。継続率の勝負で不利 |
| C' | 片手で遊べて夫婦で笑えるゲーム | **ADR-0002 と最も噛み合う**（状態・順序・並行性を持つ）。利用場面（片手・無音・中断）が設計要件として明確。共感 × ゲームの組み合わせは既存が見つからなかった | 「面白い」の水準を自分で出す必要がある。夫婦 2 人が関与する = 通信・同期でスコープ増。「情報が自然に入る」は教育ゲームの古典的難所で、面白さと学習が両立しにくい |
| D' | 何も足さず A のまま出す | 最速。2〜3 週間に確実に収まる | ユーザー本人が「わざわざ作る良さがない」と判断済み。作る理由が無い |
