# 調査: M-2 のゲーム性を詰める

**この調査で何を決めたいのか**: ISS-09。M-2 に「意味のある選択」があるか。
無いなら、共有をどれだけ磨いても成立しない。

調査日: 2026-09-02 / → ADR 候補 / 対象 ISS-09
ユーザー指摘 2026-09-02：「共有を大切にするにしても、それはゲーム性の上に成り立つ」

> 数値は全て**仮**。バランスは触って決めるものなので、ここでは構造だけを固める。
> 画面設計・データ構造には踏み込まない（基本設計フェーズの担当）。

## 1. ゲーム性の定義

このゲームが成立するかは、**意味のある選択があるか**の一点に尽きる。
意味のある選択とは、どちらを選んでも何かを失う選択のことである。
一本道の最適解があるなら、それは作業であって遊びではない。

以下、ジレンマを 3 つ用意できるかを検討する。

## 2. 状態

| 持ち主 | 値 | 意味 |
| --- | --- | --- |
| 親 | **覚醒度**（0〜100） | 0 = 熟睡、100 = 完全に起きている |
| 親 | **手札** | トントン / ミルク / 抱っこ / オムツ 等。その日の並びはシードで決まる |
| 親 | **慣れ** | 同じ手を受けるほど、その手への対処が上手くなる |
| 赤ちゃん | **元気** | 泣くと減る。減ると手が出せなくなる |
| 共通 | **時刻** | 21:00 〜 6:00。1 ターン 30 分。**有限**（仮に 18 ターン） |

**スコアは「親を完全覚醒させた回数」。**
ただし、**親が深く寝ているほど、起こしたときの効きが大きい。**

## 3. ジレンマ 1：すぐ泣くか、深く寝るまで待つか

親の覚醒度が高いうちに泣いても、あまり効かない。
覚醒度が下がりきってから泣くほど、大きく起こせる。

- 待てば効率が上がる
- **しかし夜は有限**。待っている間にターンが減る
- さらに、待っている間に**自分の元気も回復する**が、親の慣れも回復する

→ 「効率を取るか、回数を取るか」。**時間が有限なので、常に最適な待ち時間は存在しない。**
その日の盤面（親の初期覚醒度、手札）によって答えが変わる。

## 4. ジレンマ 2：親の対抗手段は、赤ちゃんにとって損得の両面を持つ

ここが「わかる」と「ゲーム性」が同時に成立する場所である。

| 親の手 | 赤ちゃんへの効果 |
| --- | --- |
| トントン | 赤ちゃんの手を封じる。ただし親の覚醒度はあまり下がらない |
| ミルク | **元気が回復する**。ただし飲んでいる間は行動できず、ターンを失う |
| 抱っこ | 親の覚醒度が上がる（＝こちらの得）。ただし**落ち着いてしまい**、次に泣きにくくなる |
| オムツ替え | 親が完全に起きる。ただし処理が終わると親は寝直しやすくなる |

**親の対処が、こちらにとって一方的な損にならない。**
だから「わざと対処させる」という戦い方が生まれる。
ミルクを引き出して元気を回復し、後半に備える、といった判断ができる。

これは実際の育児の感覚（抱っこすると落ち着く、ミルクで時間を稼げる）と一致しており、
**当事者には説明不要で伝わる。**

## 5. ジレンマ 3：寝たふり → 置いた瞬間

**必殺技。**数ターン何もしないでいると、親は「寝た」と判断して布団に置こうとする。
置かれた直後に泣くと、**この夜で最大の一撃**になる（背中スイッチ）。

- リスク 1：寝たふりの間、ターンを失う
- リスク 2：**本当に寝てしまう可能性がある**（＝その時点で夜が終わる）
- リスク 3：**親は学習する。**一度やられると、次からは置き方が慎重になり、
  成功率が落ちる。夜に何度も使えない

→ 「いつ切るか」の一回性の判断になる。
**これが当事者に最も刺さる要素**であり、同時にゲームとして最も緊張する瞬間になる。

## 6. 乱数の置き場所（確認）

[game_mechanic_3.md](game_mechanic_3.md) 1 節の原則をそのまま適用する。

- **シードで決まるもの**：親の初期覚醒度、手札の並び、その日の出来事、
  寝たふりの成功判定に使う乱数列
- **決まらないもの**：プレイヤーがいつ何を選ぶか

同じ日の盤面は夫婦で完全に同じ。**結果の差は選択だけから出る。**
乱数は消費されるが、消費の順序が選択で変わるため結果は分岐する。

## 7. 毎日やる理由

- 盤面が日替わり（今日の親は寝不足度が高い、今日は手札にミルクが無い、等）
- 夫婦が同じ盤面を遊ぶので、比較が成立する
- 過去の日には戻れない（Wordle 方式）

## 8. 制約への適合

| 制約 | 適合 |
| --- | --- |
| 片手（親指のみ） | 毎ターン 3〜4 択をタップするだけ |
| 暗所 | 暗い配色。テキスト中心 |
| 無音・バイブ禁止 | 演出は言葉と間のみ。元々そう設計している |
| 中断される | ターン境界で保存。1 ターンが独立している |
| 通信なし | 結果テキストを貼るだけ |
| 2〜3 週間 | 1 画面 + テキスト。状態は数個。**現実的** |
| [ADR-0002](../decisions/ADR-0002-test-harness.md) | シード + 選択列 → 同じ結果。ハーネスがそのまま機能する |

## 9. 懸念（正直に）

- **単調化のリスク**：「寝たふり → 背中スイッチ」が強すぎると毎回それをやるだけになる。
  親の学習（5 節リスク 3）で抑えるが、**バランスが取れるかは触るまで分からない**
- **1 回の長さ**：18 ターンは 5〜10 分程度。寝かしつけ後には合うが、
  中断前提なら短いほうがよい可能性がある
- **選択肢の深さ**：3〜4 択が浅く感じられる恐れがある。
  深さは「親の状態を読むこと」から出す設計だが、実証されていない
- **題材のリスク**：産後の状況によっては笑えない（→ [game_mechanic_3.md](game_mechanic_3.md) 5 節）

## この調査から導く結論

**ジレンマは 3 つ用意できた。**「待つか泣くか」「対処を引き出すか避けるか」
「寝たふりをいつ切るか」。いずれも一本道の最適解が無く、その日の盤面で答えが変わる。
**ゲームとして成立する構造にはなっている。**

**ただし、面白いかどうかは紙の上では決まらない。**
9 節の懸念（単調化・長さ・深さ）は、いずれもバランスの問題であり、
触ってみるまで判定できない。

→ **`scratch/` での最小プロトタイプによる検証を提案する。**
[CLAUDE.md](../../../CLAUDE.md) は `scratch/` での技術検証プロトタイプを例外として認めている。
ただし本件は技術検証ではなく**面白さの検証**であり、
例外の範囲に入るかはユーザーの判断が要る。**勝手に始めない。**
