## 書き方のルール

- 1 行 1 要件。「〜できる」で終わる形にする（実装手段を書かない）
- 判定できない要件は書かない（「使いやすい」→ 何をもって満たすかを書く）
- 優先度は Must / Should / Could。Must は全てテストで担保する
- 後から足すときは新しい ID を発番する。既存 ID の意味は変えない
