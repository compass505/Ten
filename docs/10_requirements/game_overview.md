## 1. 一行で言うと

**あなたは生後 1 か月の赤ちゃんになって、寝ようとしている親を起こす。**
一晩（ゲーム内 21:00〜6:00）を実時間 5 分以内で遊び、
**親を何回ベッドから出させたか**を競う。盤面は日替わりで、夫婦は同じ日に同じ盤面を遊ぶ。

## 2. 誰がいつ遊ぶか

赤ちゃんを寝かしつけたあと、抱いたままソファーで**片手だけが空いている**数分間。
暗く、音は出せず、いつ中断されるか分からない。夫婦それぞれが別々に遊び、
結果のテキストを LINE 等に貼って見せ合う。通信もアカウントもサーバーも持たない。

## 3. 高得点の取り方

得点は**親を完全に覚醒させた回数**。親は完全に起きたあと、あなたが静かにしていれば
また寝る。つまり一晩は、この周回の繰り返しになる。

```
① 何もしない ── 親の覚醒度が下がる／元気が回復する／親の「慣れ」が戻る
           ただし待つほど、赤ちゃん自身が寝落ちする確率が上がる（REQ-047）
      ↓
② 覚醒度が底に着く ── 一番効くタイミング（REQ-012）。ただし正確には見えない
      ↓
③ 起こしにいく ── 親が山札から 1 枚切って対処してくる（＝山札が減る）
      ↓
④ 覚醒度が上限 ── 親がベッドを出る ＝ +1 点
      ↓
①へ。ただし山札が尽きていれば、そこで夜は終わる（REQ-042）
```

**高得点＝この周を何回まわせるか。**一晩 5 分という時間と、親の山札の枚数が、
両側から上限を押さえている。

## 4. 一晩の例

> 数値は全て仮。バランスは基本設計フェーズで決める。

| ゲーム内時刻 | 起きること | あなたの判断 |
| --- | --- | --- |
| 21:00 | 仰向けで天井が見える。**親はまだ起きている** | 今泣いても効かない。待つ |
| 21:40 | 親の覚醒度が下がってきた。元気は満タン | 泣く → 親が**トントン**（山札 −1）。効きは小さく、トントンへの**慣れ**が付く |
| 22:30 | 手足をばたつかせる | 親が**ミルク**（山札 −1）。元気は回復するが、飲む間は動けず時間を失う |
| 23:10 | **出来事: オムツが汚れる** | 山札に**オムツ替えが 1 枚追加**される。好機 |
| 0:00 | **親が深く寝た。最大のチャンス** | **目を閉じる**（＝寝たふり）。寝室の像が消え、窓の明るさ以外は何も見えない |
| 0:00〜 | 親が「寝た」と判断して抱き上げ、布団に置こうとする | **いつ目を開けるかが賭け。**待ちすぎると**本当に寝てしまい、夜が終わる** |
| 0:02 | 置かれた直後に目を開けて泣く（背中スイッチ） | **この夜で最大の一撃。+1 点** |
| 1:30 | 親が寝直す。手つきが雑になってきた（＝山札が減っている） | 2 回目を狙う。寝たふりは 2 回目以降、成功率が落ちる |
| 4:20 | 親が最後の 1 枚を切る | **親が寝るのを諦めてリビングへ行き、夜が終わる** |

## 5. あなたが操作できるもの

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 首を振る（可動範囲は狭い）。天井・親の顔・親の手が見える |
| 泣く | 覚醒度を上げる。元気を消費する |
| ぐずる | 弱く覚醒度を上げる |
| 手足をばたつかせる | 親の対処を引き出しやすい |
| 目を閉じる | **寝たふり。**寝室の像を失う。窓の明るさで時間帯だけは分かる |

**全て片手の親指だけで届く。同時に 2 か所を触ることは要求しない。**
音とバイブは一切使わない。

## 6. 状態

| 持ち主 | 状態 | 動き方 |
| --- | --- | --- |
| 親 | **覚醒度** | 0 = 熟睡、最大 = 完全に起きている。**低いほど、起こしたときの効きが大きい** |
| 親 | **慣れ** | 同じ対処を繰り返すほど上手くなり、同じ行動から受ける覚醒度の上昇量が下がる。何もしない間に戻る |
| 親 | **山札** | その夜に切れる対処の有限な束。**総枚数と内訳は日付シードで決まる**（REQ-041） |
| 赤ちゃん | **元気** | 行動で減り、何もしていない間と親の対処で回復する。尽きると行動できない |

## 7. 親の 4 つの対処と、その損得

**どの対処も、赤ちゃんにとって一方的な損にはならない。**だから「わざと対処させる」が戦術になる。
**そして、どの対処も山札を 1 枚消費する。**

| 対処 | 得 | 損 |
| --- | --- | --- |
| トントン | 赤ちゃんが少し落ち着き、元気が回復する | 手を封じられる。親の覚醒度もあまり上がらない |
| ミルク | 元気が回復する | 飲んでいる間は行動できず、時間を失う |
| 抱っこ | 親の覚醒度が上がる | 落ち着いてしまい、次に泣きにくくなる |
| オムツ替え | 親が大きく起きる | 処理が終わると親は寝直しやすくなる |

## 8. 夜の終わり方は 3 通り

| 終わり方 | 要件 |
| --- | --- |
| 6:00 になる | REQ-007 |
| 赤ちゃんが本当に寝てしまう（寝たふり中 / **何もしないで待っている間**） | REQ-018 / REQ-047 |
| **親の山札が尽きる**（寝るのを諦める） | REQ-042 / REQ-050 |

**終わり方そのものは得点に加減しない**（REQ-054）。結果テキストにどれで終わったかが入る。

## 9. その夜の出来事

シードで決まった時刻に発生し、**山札の枚数か、赤ちゃんの状態を変える**（REQ-043）。
種類は基本設計で決める。想定している役割は次のようなもの。

| 出来事 | 効果 |
| --- | --- |
| オムツが汚れる | 山札にオムツ替えが 1 枚追加される |
| （出来事は山札と赤ちゃんの状態のほか、**親の状態と視界にも作用してよい**。REQ-055） | |
| もう一人の親が起きてくる | 山札が増える。夜は延びるが、対処が厚くなる |
| 親のスマホが鳴る | 覚醒度が少し上がる |
| 親が寝返りを打つ | 顔が視界から消え、覚醒度が読めなくなる |
| おなかが空く | 元気が減り続ける |

## 10. 状態の見せ方（数値を出さない）

**画面に数値・ゲージ・アイコンは出ない**（REQ-044 / [ADR-0010](decisions/ADR-0010-no-numbers.md)）。
全ての状態は**寝室の中の見た目**で分かる。

| 段階 | 親の顔 | 親の手 | 反応 | 部屋 |
| --- | --- | --- | --- | --- |
| 序盤（山札が厚い） | 目を開けてこちらを見る | トントンのリズムが規則正しい | 泣いたらすぐ来る | 暗いまま |
| 中盤 | 目を閉じたまま | リズムが乱れる、雑になる | **一拍遅れる** | 暗いまま |
| 終盤（残りわずか） | 表情が抜ける | **手が途中で止まる** | **明らかに遅い**（REQ-046） | **電気をつけっぱなしにする** |

**段階と実際の値の対応は固定で、段階は粗い**（REQ-045）。
規則を完全に覚えても、**「終盤に入った」は分かるが「あと 2 枚か 3 枚か」は分からない。**
ただし端点（山札が空・覚醒度が上限・夜明け直前）だけは正確に分かる。

明度差だけに頼らず、輪郭・模様・姿勢・動きの周期でも同じことを伝える（REQ-044）。
音もバイブも使えないため、**対象の 2 人が全段階を識別できるかを実機で確かめる**まで、
この見せ方が成立するとは言えない。

## 11. 何が「腕」で、何が「運」か

| 分類 | 中身 |
| --- | --- |
| **あなたの選択で決まる** | いつ泣くか / どの対処を引き出し、どれを避けるか（山札の管理）/ 寝たふりを何周目にいつ切るか |
| **その日固定（盤面）** | 親の初期覚醒度 / 山札の枚数と内訳 / その夜の出来事。**何度遊んでも同じ** |
| **プレイのたびに変わる（判定）** | 寝たふりの成否 / 本当に寝てしまうか / 親がどの対処を選ぶか（REQ-048） |

**夫婦は、同じ日の同じ回数目のプレイなら同じ運を引く。**
盤面は何度遊んでも同じだが、判定はプレイごとに変わるので、
**1 回目で「2 回目の寝たふりは成功する」と分かっても、2 回目のプレイでは通用しない**
（→ [ADR-0011](decisions/ADR-0011-per-play-randomness.md)）。
最高成績が何回目に出たかは 2 人で違うので、結果テキストに回数が入る（REQ-031）。

## 12. 3 つのジレンマ

1. **待つか泣くか** — 待つほど親が深く寝て効きが上がるが、**夜は有限**
2. **対処を引き出すか避けるか** — どの対処にも得と損があり、**さらに山札を削る。
   引き出しすぎると親が寝るのを諦めて夜が終わる**
   （なお、待つこと自体にも代償がある。待ちすぎると赤ちゃんが寝落ちする）
3. **寝たふりをいつ切るか** — 最大の一撃だが、時間を失い、本当に寝れば夜が終わり、
   繰り返すほど成功率が落ちる

## 13. 1 日の遊び方と、見せ合い方

- その日の盤面は**何度でも遊べる**。過去の日の盤面は遊べない
- その日の結果は、**最高成績のプレイ 1 回分**（同点なら先に遊んだほう）
- 結果テキストには、**その回に起きた出来事の実況（3 文以内）** と、
  **その日の通算プレイ回数 / 何回目のプレイの結果か**が入る
- 盤面の答え（親の初期状態・山札の並び・出来事の順序）は結果テキストに含めない
- コピー / 共有でそのまま LINE 等に貼る
