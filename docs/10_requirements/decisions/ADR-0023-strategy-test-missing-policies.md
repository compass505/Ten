# ADR-0023: TC-069 に「寝入りばな狙い」と「溜めて待つ」を足し、独走をバランスで崩す

## 背景

[balance.md](../../20_basic_design/balance.md) 15 節は「得点のレンジが 0〜1 に縮んでいて、
**REQ-056（支配戦略が無い）が判定できない**」を宿題にしていた。
`scratch/balance/`（48 シード × 10 方針）で測ると、次の 2 つが分かった。

1. **TC-069 の 5 方針（連打 / 溜め / 寝たふり / 混ぜる / 放置）は、どれも「起きている親を待つ」をしない。**
   起きている親に撃ち続けると落ち着きが止まり（REQ-030）、再加点できないので**得点が 1 に張り付く。**
   0〜1 に縮んで見えたのは、ゲームではなく**測った方針のせい**だった
2. **親の寝入りばなの周期を読んで、溜めた泣きだけを当てる方針が 48/48 シードで独走した**（平均 9.0、他の最良 2.9）。
   寝入りばなは周期が決まっていて予兆が読める（REQ-061）うえ、`Grace` の間は札を引かせていなかった

**TC-069 は通っていたが、REQ-056 は破れていた。**テストケースの欠陥である。

## 選択肢

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| A. テストはそのまま、バランスだけ直す | テストに触らない | **独走を見張る方針がテストに無い**ので、次に値を動かしたとき同じ独走が戻っても誰も気づかない |
| B. 「寝入りばな狙い」だけ足す | 独走を見張れる | **比較対象が待たない方針だけ**なので、待つ方針はどれでも独走に見える。バランスをどう直しても赤いまま（2 と同じ理由） |
| **C. 「寝入りばな狙い」と「溜めて待つ」を足し、バランスで独走を崩す（採用）** | 独走を見張れて、比較が公平になる | テストに方針を足すので、**「通すために比較相手を足した」と読める** |
| D. 寝入りばなに乱数を入れる | 周期読みが効かなくなる | REQ-061 の「予兆が読める」と ADR-0015 の核を壊す |

## 決定

**C を採用する。**

決め手は、**待つ方針と待たない方針を比べても REQ-056 は測れないこと。**
REQ-056 は「どの行動も他より常に優れていない」であって、「上手な方針が下手な方針に勝たない」ではない。

「通すために足した」でないことは、**足した順番と、値を戻したときの結果**で示す。

| 手順 | TC-069 |
| --- | --- |
| 1. 「寝入りばな狙い」を足す（15 節の値のまま） | **赤**（24/24 で独走） |
| 2. 規則（`Grace` でも札を引く）と 5 つの値を直す | **赤**（まだ 24/24。比較相手が待たない方針だけ） |
| 3. 「溜めて待つ」を足す | **緑** |
| 4. **値だけを 15 節に戻す**（方針は 2 つとも足したまま） | **赤**（寝入りばな狙いが独走） |

**4 が赤いので、緑にしたのはテストの方針ではなくバランスの修正である。**

### 確定する内容

1. `StrategyTests.Policy` に `GraceSnipe`（寝入りばな狙い）と `ChargeWait`（溜めて待つ）を足す。
   **合格線（80%）とシード数（24）は動かさない**
2. `Sim.DrawCare` は、親が `Grace` のときも札を引く（REQ-049 と同じ趣旨の抜け道を塞ぐ）
3. `Tuning` の 5 値を変える（balance.md 16 節）。**テストの期待値には入らない**（ADR-0012）

## 結果

- TC-069 が、**周期の読める寝入りばなの独走**を見張れるようになった
- 得点のレンジは 0〜5 に開いた。**同点が多い**（刻みが粗い）ので、単独勝ちの数え方は今のまま据え置く
- **寝たふり型は 0 点のまま。**これは REQ-056 違反ではない（弱い方針があるのは許される）が、実機で見る

**ADR-0005 に照らすと、書いた Claude がテストに方針を足し、同じ Claude が確定させている。**
ADR-0020 と同じく、別の目で検めるまで受容したリスクを持つ。

## この決定が崩れる条件

- 実機で人が遊んで、**周期読みが画面から実際には読めない**と分かったとき（計測は「顔を見続けている」前提）。
  そのときは `GraceSnipe` が現実の方針ではなくなり、1 の根拠が弱まる
- 得点の刻みを細かくする（REQ-023 を覆す）とき。同点の扱いが変わり、合格線の意味が変わる
