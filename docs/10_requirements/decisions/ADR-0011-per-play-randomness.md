# ADR-0011: 判定に使う乱数の通番に「その日のプレイ回数」を含める（盤面は日固定、運は毎回変わる）

- ステータス: **Accepted**（2026-09-02 承認）
- 日付: 2026-09-02
- 関連: ISU-44 / ISS-17 / [ADR-0008](ADR-0008-randomness-scope.md)（用途表の通番を差し替える） /
  [ADR-0010](ADR-0010-no-numbers.md) / REQ-024 / REQ-048

## 背景

[ADR-0008](ADR-0008-randomness-scope.md) は用途別ストリームを採用し、
通番を「**その夜で何回目の寝たふりか**」と定義した。
一方 REQ-024 は「その日の盤面を**何度でも遊べる**」としている。

**この 2 つが噛み合うと、乱数が攻略表になる**（Codex ISU-44）。
1 回目のプレイで「2 回目の寝たふりは成功、3 回目は寝落ち」と判明すれば、
2 回目以降は**既知の成功通番だけを踏む再生問題**になる。
REQ-017（繰り返すほど成功率が下がる）ではこれを防げない。

同じ理由で **[ADR-0010](ADR-0010-no-numbers.md) の決め手も崩れていた。**
「遊び込んだ後まで読み切れない」と書いたが、ずれは日ごとに固定なので、
その日の 1 回目で対応が割れる。防げていたのは日をまたぐ攻略だけだった。

**今決める必要があるのは、通番の定義が決まらないと REQ-048 を書けないからである。**

## 選択肢

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| **A. 判定用の通番にプレイ回数を含める（採用）** | 盤面は日固定のままなので「夫婦が同じ盤面を遊ぶ」意味が残る。**当日中の攻略再生だけが消える。**要件の変更が小さい | 「同じ日なら夫婦は完全に同じ運」ではなくなる。正確には「同じ日の**同じ回数目**なら同じ運」 |
| B. 1 日 1 回に戻す | 賭けが本物になる。比較が完全に公平。実装が最も軽い | 誤タップ・中断・寝落ちでその日が終わる。**産後の生活では中断が日常**。REQ-024 / 025 / 031 / 037 をまとめて差し替える ADR が要る |
| C. 攻略できるまま受容する | 何も変えなくてよい | ADR-0010 の決め手が成立しないままになる。**夫婦の比較が「探索の徹底度」の比較になる** |
| D. 盤面ごと毎回変える | 攻略が完全に消える | **日替わりの盤面を夫婦で共有する**という ADR-0007 の共有の根拠が消える。作る理由が消える |

## 決定

**A を採用する。**

決め手は、**夫婦が「同じ盤面」を遊ぶ意味を保ったまま、
当日中の攻略再生だけを消せるのが A だけだったこと。**
B は成立するが生活に合わず、C は問題を放置し、D は共有の根拠そのものを壊す。

### 通番の定義（[ADR-0008](ADR-0008-randomness-scope.md) の用途表を差し替える）

ADR-0008 本文は書き換えない。以後、通番の定義はこの表を参照する。

| 用途 | 通番 | プレイ回数を含むか |
| --- | --- | --- |
| `parent_initial` | 通番なし（その日 1 回） | **含まない**（盤面） |
| `parent_hand` | 配る順 | **含まない**（盤面） |
| `night_event` | 出来事の順 | **含まない**（盤面） |
| `sleep_pretend` | その日の n 回目のプレイの、その夜で m 回目の寝たふり | **含む**（判定） |
| `fall_asleep` | 同上 | **含む**（判定） |
| `parent_choice` | その日の n 回目のプレイの、その夜で m 回目の対処 | **含む**（判定） |

`display_bias` は [ADR-0010](ADR-0010-no-numbers.md) の書き直しにより**廃止**した。

## 結果

固定されるもの:

- **盤面**（親の初期覚醒度・山札の枚数と内訳・出来事の種類と時刻）は**その日固定**。
  何度遊んでも同じものが出る
- **判定**（寝たふりの成否・本当に寝てしまうか・親がどの対処を選ぶか）は
  **プレイのたびに変わる**
- 夫婦の「その日の 1 回目同士」は同じ運。2 回目同士も同じ
- プレイ回数を**保存に含める**必要がある（→ REQ-053 と合わせて REQ-032 を補う）

諦めたもの:

- **「同じ日なら夫婦は完全に同じ運を引く」という単純さ。**
  正確には「同じ日の同じ回数目なら同じ運」であり、
  **最高成績が何回目に出たかは 2 人で違う**（REQ-031 で回数を結果に載せているのはこのため）
- 1 回目のプレイで得た情報を 2 回目に活かす楽しさ。盤面（山札の内訳・出来事）については
  残るが、判定については残らない

覆すコスト:

- 現時点ではドキュメントのみ
- テスト作成フェーズ以降に B（1 日 1 回）へ移すと、保存・結果・共有の要件がまとめて変わる

## この決定が崩れる条件

- プレイ回数を保存できない状況（保存の破損 → REQ-033）で通番が巻き戻り、
  再生問題が復活すると判明したとき
- 「何回やっても運が変わる」ことが、賭けではなく**運任せ**に感じられると判明したとき
- 「同じ回数目でないと同条件にならない」ことが、夫婦の見せ合いを面倒にすると判明したとき
