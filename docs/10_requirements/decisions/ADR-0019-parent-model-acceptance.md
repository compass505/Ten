# ADR-0019: 親モデルの合格条件を「ゲーム内の見え方」に置き、作り込みをそこで止める

- ステータス: **Proposed**（人間の承認待ち）
- 日付: 2026-09-12
- 関連: SET-01 / [setting.md](../../20_basic_design/setting.md) 4・5・10 節 /
  [ADR-0010](ADR-0010-no-numbers.md) / [ADR-0018](ADR-0018-parent-is-mother.md) /
  REQ-044 / REQ-045 / REQ-046 / REQ-061 / NFR-007

## 背景

親の 3D モデル制作は `scratch/visual/parent/` で **r4 から r55 まで 50 周以上**回っているが、
一度も完成していない。`LATEST.md` / `CHECKPOINT-r54.md` / `CHECKPOINT-r50.md` の
「残る主要差分」は **3 回とも同じ 5 項目**（髪の毛束、耳周りと襟足、眉と鼻、布の折れ目、
書き出し後の髪の質感）である。

**原因は、合格条件が「元絵 `parent-model-sheet-v2-cute.png` と同じ顔になること」だったこと。**
元絵は 2D の生成画で、スタジオ照明・正面・高解像度である。
メッシュとシェーダで完全一致は原理的に到達しないため、
「まだ差がある」といくらでも書き続けられる。

**そしてゲームは、その条件で親を一度も表示しない。**

| ゲーム内の条件 | 出典 |
| --- | --- |
| 画素の相対輝度の平均が **0.1 以下**の暗所 | NFR-007 |
| カメラは床から **0.28 m** の一点に固定、視野角 70° | [setting.md](../../20_basic_design/setting.md) 3 節 / `scratch/mvp/index.html:395` |
| 顔が見えるのは首角度 **−1°〜39°** のときだけ、距離 **約 0.93 m** | [setting.md](../../20_basic_design/setting.md) 3 節 |
| 光源は窓からの月明かりと、たまに点く暖色の天井灯だけ | [setting.md](../../20_basic_design/setting.md) 7 節 |
| 必要なのは**手と顔だけ**。歩行アニメも全身も要らない | [setting.md](../../20_basic_design/setting.md) 9 節 |

この条件では、髪の毛束の細さも布の折れ目もほぼ見えない。
逆に**暗闇で覚醒度 4 段階が見分けられるか**は致命的に効く（REQ-044）。

**今決める必要があるのは、これが決まらないと r56 以降も同じ 50 周を繰り返すからである。**
あわせて [setting.md](../../20_basic_design/setting.md) 10 節の
**SET-01「親の造形をどこまで作り込むか」**を決着させる。

## 選択肢

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| A. 元絵一致を続ける（現状維持） | 見栄えは上がり続ける | **終了条件が無い。**50 周で証明済み。ゲームが使わない情報にコストを払う |
| B. 周回数か時間で打ち切る（「あと 5 周で終わり」） | 確実に終わる | **終わった時点の品質が保証されない。**仕様を満たさないまま次へ進む |
| C. 人間が見て「もういい」と言うまで | 判断が正しい | 本人の時間を毎周奪う。[ADR-0005](ADR-0005-agent-roles.md) の検める側の負荷が青天井 |
| **D. ゲーム内条件のレンダで仕様を満たすかで判定する（採用）** | **測れて、終わる。**ゲームが実際に使う情報だけにコストを払う | 見栄えの良い宣材が別途要る。近距離では粗いまま |

## 決定

**D を採用する。**

決め手は、**ゲームがモデルシートの条件で親を一度も表示しないこと。**
判定に使う絵が本番と違う限り、どれだけ周回しても本番での可読性は保証されない。
逆に本番条件で判定すれば、周回は仕様を満たした時点で必ず終わる。

### 確定する内容

1. **合格判定はすべて、ゲーム内カメラ（床から 0.28 m、視野角 70°）・
   ゲーム内照明（平均相対輝度 0.1 以下）のレンダで行う。**
2. 判定する内容は次の 4 つ。いずれも
   [setting.md](../../20_basic_design/setting.md) の該当節をそのまま条件にする。

   | 判定 | 内容 | 出典 |
   | --- | --- | --- |
   | A | 覚醒度 4 段階が、文字なしで見分けられる。**グレースケール化しても順序が保てる** | 4.1 / REQ-044 / REQ-045 |
   | B | 寝入りばな（予兆 4.5 秒 → 本体 1.8 秒）が、顔を見ていれば分かる | 4.2 / REQ-061 |
   | C | 手つきで山札残量 3 段階が分かる | 4.3 / REQ-046 |
   | D | 4 つの対処が動きで見分けられ、それぞれの「損」が絵で伝わる | 5 節 / REQ-013 |

3. **SET-01 を決着させる。作り込みは 2. を満たす最小限で止める。**
   「元絵に近づけるため」を理由に造形・髪・布のディテールを増やさない。
4. **モデルシートの役割を、合格判定から方向性の出典に降格する。**
   採用する出典は [ADR-0018](ADR-0018-parent-is-mother.md) の
   `parent-model-sheet-v4-e2-long-cute-30s.png` と、
   `parent-hand-sheet-v2.png`（赤ちゃん視点の手 7 姿勢）。
   **顔の造形の一致は求めない。**
5. **三角形数の暫定目標を 30,000 とする。**r55 の 98,927 は暗所・固定カメラには過剰。
   守れない場合は Codex が理由と実数を報告して止まる（勝手に基準を下げない）。
   **実機で測るまでこれは仮の数字である。**

## 結果

固定されるもの:

- 周回に**終了条件が付く**。判定 A〜D を満たした時点で完成とする
- 制作の優先順位が変わる。**輪郭・姿勢・動きの周期 > 表面のディテール**。
  これは [ADR-0010](ADR-0010-no-numbers.md)（明度差だけに依存しない）と同じ向き
- 検証成果物が判定の証拠として残る（静止画・短い動画・平均輝度の実測値）

諦めたもの:

- **近距離での作り込み。**ストアの宣材やアイコンには別途、明るい条件での絵が要る
- 元絵と同じ顔になること。**これは最初から到達不能だったので、失ったのは期待だけ**
- 作り込みを上げれば得られたはずの表現力。ただし暗所では見えない

**後で覆すコスト**: 合格条件を上げ直すこと自体は安い（判定を足すだけ）。
高いのは逆で、**低い基準で完成扱いして実装フェーズへ進んだ後に作り直す**場合。
判定 A〜D は REQ-044 / 045 / 046 / 013 に直結しているため、
ここを緩めると要件が未達のまま実装に入る。

## この決定が崩れる条件

- **実機で判定 A〜D を満たしたモデルが、実際には見分けられなかったとき。**
  レンダと実機の差（画面の輝度・視野角・フレームレート）で起こりうる。
  NFR-001 の通しプレイと同じ機会に見る
- 三角形数 30,000 で実機の性能が足りない、または大幅に余裕があると分かったとき
- 判定 A〜D をすべて満たしても、**本人が見て「これでは遊びたくない」と判断したとき**。
  そのときは魅力の条件が判定に欠けていたということなので、判定を足して再発番する
