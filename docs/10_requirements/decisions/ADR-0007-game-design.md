## 背景

[ADR-0006](ADR-0006-concept.md) で「夫婦で笑う共感ゲーム」に決めたが、
**中身が決まらないと要件を書けない。**

検討の過程で 2 つの前提が潰れている。

1. **「交互に遊ぶ」は成立しない。**夫婦それぞれが赤ちゃんを抱えている時間はバラバラで、
   かつまとまって訪れる。相手の手番を待つ構造はこの生活では止まる
   （ユーザー指摘 2026-09-01）
2. **ターン制は渋い。**手触りのある遊びにする必要がある（ユーザー指摘 2026-09-02）

**今決める必要があるのは、これ以上は紙の上で判断できる材料が出ないからである。**
残る懸念（3D 酔い・単調化・手触り）は、いずれも触らないと判定できない。

## 選択肢

| 案 | 利点 | 欠点 |
| --- | --- | --- |
| A. 片手お絵かき伝言 | Draw Something / Gartic Phone という二重の前例。下手さが面白さになる | **交互が前提で成立しない。**お絵かきは既存が多く、作る理由が薄い |
| B. ターン制の夜泣きサバイバル（親側） | 実装が最も軽い。ジレンマを作りやすい | 大変さの**再演**になる。ユーザー判断で「渋い」 |
| C. ターン制の立場逆転（赤ちゃん側） | 大変さを**反転**でき、笑いに変わる | 同上。手触りが無い |
| **D. 一人称アクション・生後 1 か月（動けない）（採用）** | **「寝たふり＝目を閉じる＝画面が暗くなる」が UI なしで成立する。**移動が無いので 3D 酔いのリスクが最も低く、工数も最も低い。ペルソナの現在と一致する | 首の可動範囲の狭さが、心地よいぎこちなさになるかストレスになるか未検証 |
| E. 一人称アクション・ハイハイ期 | 移動と探索ができ、遊びの幅が広い | **3D 酔いの条件を全て満たす**（床すれすれ・一人称・連続する上下動）。工数も跳ねる |
| F. 三人称アクション | 酔いにくい。キャラクターが見えて可愛げを出せる | 「置かれる瞬間」「目を閉じる」が、他人事の絵になる |

## 決定

**D を採用する。**

決め手は、**このゲームの核となる駆け引き「寝たふり」が、
一人称・動けない構成でのみ、UI や数値なしで成立すること。**

目を閉じれば画面が暗くなり、何も見えなくなる。その間に親が近づいているのか、
布団に置こうとしているのかが分からない。**いつ目を開けるかが、そのまま賭けになる。**
三人称でも、ターン制でも、この賭けは説明文でしか表現できない。

### 確定する内容

1. **視点**: 一人称。仰向けの赤ちゃん（Ten）。**移動しない**
2. **操作**: 指のドラッグで首を振る（可動範囲は狭い）+ ボタンで行動
   （泣く / ぐずる / 手足をばたつかせる / 目を閉じる）
3. **目的**: 親を起こす。親が深く寝ているほど、起こしたときの効きが大きい
4. **ジレンマ 3 つ**:
   待つか泣くか / 親の対処を引き出すか避けるか / 寝たふりをいつ切るか
5. **乱数**: **盤面の生成にのみ使い、勝敗の決定には使わない。**
   日付から決まる固定シードで、親の初期状態・手札の並び・出来事が決まる
6. **共有**: 夫婦は同じ日の同じ盤面を各自プレイし、**結果テキストだけを既存の手段
   （LINE 等）に貼る**。通信・アカウント・サーバーを持たない（Wordle 方式）
7. **段階**: 生後 1 か月（動けない）のみ。寝返り・ハイハイは拡張として後回し

## 結果

固定されるもの:

- **移動を持たない**ため、地形・当たり判定・移動アニメーションが不要になる。
  3D 空間は寝室 1 部屋、しかも見える範囲だけでよい
- 必要なアニメーションは**親の手と顔のみ**（トントン / 抱き上げ / 置く）。
  Asset Store に「親が赤ちゃんをトントンする」動きは無いため、ここは自作になる
- 音・バイブを使わないため、音アセットは一切不要
- 乱数を盤面生成に限定したことで、**結果の差はプレイヤーの選択だけから出る。**
  これが「見せ合う意味」を作ると同時に、[ADR-0002](ADR-0002-test-harness.md) の
  決定論と一致する

諦めたもの:

- **ハイハイ期の探索の楽しさ。**3D 酔いのリスクが高すぎる
- 三人称の可愛げ。キャラクターの姿は基本的に見えない
- リアルタイム通信による同時プレイ

覆すコスト:

- 現時点ではドキュメントのみ。実装後に視点や段階を変えると、
  3D 空間・アニメーション・操作系がまとめて作り直しになる

## この決定が崩れる条件

- **抱き上げの回転演出で 3D 酔いが起きると判明したとき。**
  演出を抑えても酔うなら、一人称そのものを見直す
- 首の可動範囲の狭さが、心地よいぎこちなさにならず単なるストレスだと判明したとき
- 「寝たふり → 置かれた瞬間」が強すぎて毎回それだけになり、
  親の学習で抑えても単調さが解消しないとき
- 1 回が長すぎて、寝かしつけ後の細切れの時間に収まらないと判明したとき
- 本人または配偶者が 3D 酔いしやすい体質だと判明したとき（**未確認**）

## 承認時に受容したリスク（2026-09-02）

[Codex レビュー](../../50_review/issues.md)の指摘を未解決のまま、
ユーザー判断により Accepted とした。

- **ISU-03**: 選択肢に **2D / 2.5D の一人称リアルタイムが無い。**
  固定背景に親の手・顔・暗転を重ねれば核は成立し、3D モデル・リグ・カメラ酔いを避けられる。
  比較せずに 3D を選んでいる
- **ISU-04**: 「触らないと判定できない」と本文に書きながら、
  **プロトタイプ前に不可逆な決定を確定した**
- **ISU-05**: 「必要なアニメーションは親の手と顔のみ」は**過少見積もり。**
  リグ・表情・貫通防止・カメラ同期・寝室モデルが必要で、一人称は粗が目立つ
- **ISU-13**: 「夫婦間で交互」と「ゲーム内部がターン制」を混同している。
  各自独立の一人用ターン制なら手番待ちは発生しない。ターン制を退けた理由は「渋い」のみ
- **ISU-14**: 「乱数は勝敗の決定に使わない」と、調査の「寝たふりの成功判定に乱数を使う」が
  **矛盾している。**「同じ盤面」の範囲が未定義
- **ISU-15**: 中断・フォーカス喪失時の自動停止、入力の排他、
  片手で同時操作を要求しないことが確定事項に無い（scope.md は要求している）
- **ISU-16**: 開発中に月齢が進み、完成時には題材が過去になり始める。
  想定利用期間・盤面の種類数・何日遊べれば成功かが未定義
