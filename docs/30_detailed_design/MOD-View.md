# MOD-View — 一人称の寝室

種別: リファレンス / 層: **表示層**
更新トリガー: 見せる情報が増減したとき / 視線の対象を変えたとき
対応要件: REQ-001 / 002 / 004 / 005 / 006 / 008 / 044 / NFR-007 / 009

出典: [setting.md](../20_basic_design/setting.md)（寸法・段階の見た目） /
[screens.md](../20_basic_design/screens.md) 4.2.1（視線と情報の対応 / D-11）

## 公開 IF

```csharp
public interface IView {
    /// 毎フレーム呼ぶ。状態と段階を受け取って見せるだけ。**判断をしない**
    void Render(NightState s, Display.Stages stages, (float Yaw, float Pitch) look);
    /// いま視線が向いている対象。null は天井（何も分からない）
    GazeTarget? Gaze { get; }
}

public enum GazeTarget { ParentFace, ParentHand, Window }
```

## 満たすこと

| # | 性質 | 要件 |
| --- | --- | --- |
| V-1 | **判断をしない。**状態を受け取って見せるだけ。ここでゲームの結果が変わらない | architecture.md |
| V-2 | 天井・親の顔・親の手が視界に入りうる | REQ-001 |
| V-3 | **視線で分かることが変わる**（D-11）。3 対象は同時に視界へ入らない | REQ-006 |
| V-4 | 目を閉じている間は**完全に黒。窓の明かりだけを不透明な色で描く** | REQ-004 / ADR-0014 |
| V-9 | **閉眼中の窓の明かりは、閉じる直前の首の向きに従う。**窓を向いていなければ真っ暗（D-12） | REQ-008 |
| V-10 | **`Settling`（抱き上げ〜着地）の間、閉眼中の明かりの見え方が動く。ただし `Feint`（寝たふり失敗）の間も、同じ長さ・同じ動き方で動かす**（[ADR-0017](../10_requirements/decisions/ADR-0017-parent-moves-on-failure.md)）。**片方だけ動かした時点で寝たふり成功の通知になる** | **REQ-016** |
| V-11 | **`Settling` と `Feint` の描画を、同じコードパスから出す。**分岐して別々に書くと、片方だけ直したときに差が生まれる。差が生まれたことに気づく手段が画面側には無い（純粋層の TC-164 は状態しか見ない） | REQ-016 / ADR-0017 |
| V-5 | **数値・ゲージ・アイコンを出さない** | REQ-044 |
| V-6 | 明度差だけに依存しない。輪郭・姿勢・動きの周期で冗長化する | REQ-044 |
| V-7 | 全画面で**画素の相対輝度の平均が 0.1 以下** | NFR-007 |
| V-8 | 操作対象を画面の下半分に置く | REQ-005 |

**V-4 は実装上の落とし穴がある。**暗幕に alpha を混ぜると寝室が透けて、
REQ-004 と寝たふりの賭けが壊れる（[balance.md](../20_basic_design/balance.md) 11 節で実際に踏んだ）。
**閉眼中の描画に半透明を使わない。**

**V-3 の遮蔽はここで行う。**`MOD-Display` は「見えうる段階」を返すだけで、
カメラの向きを知らない（architecture.md の依存方向）。
