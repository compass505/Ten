# MOD-Tutorial — 初回起動の導線

種別: リファレンス / 層: **表示層**
更新トリガー: 教える内容が増減したとき
対応要件: REQ-034

出典: [screens.md](../20_basic_design/screens.md) D-09（専用の固定盤面）

## 公開 IF

```csharp
public interface ITutorial {
    /// 進行中の段。完了したら null
    TutorialStep? Current { get; }
    void Advance(NightState s);      // 状態を見て、条件を満たしたら次へ
    bool IsDone { get; }
}

public enum TutorialStep { Arousal, Vigor, Pretend }
```

## 教えること（3 つだけ。REQ-034）

| 段 | 教えること | 完了条件（**操作させて達成させる**） |
| --- | --- | --- |
| `Arousal` | 覚醒度 — 行動で上がり、待つと下がる。低いほど効く | 覚醒度を上限まで上げて 1 点取る |
| `Vigor` | 元気 — 行動で減り、待つと回復する。尽きると動けない | 元気を尽きさせ、回復を待つ |
| `Pretend` | 寝たふり — 目を閉じ、置かれた直後に泣く | 寝たふりを 1 回成功させる |

## 満たすこと

| # | 性質 | 要件 |
| --- | --- | --- |
| TU-1 | **説明文を読ませるのではなく、操作しながら知る** | REQ-034 |
| TU-2 | **日付シードを使わず、専用の固定盤面で動く。**3 つが必ず達成できる盤面 | D-09 |
| TU-3 | **その日のプレイ回数に数えない** | REQ-031 / 048 |
| TU-4 | 完了以外の出口を作らない（戻る操作を受け付けない） | screens.md 3 節 |
| TU-5 | 完了は `DeviceData.TutorialDone` に保存する | REQ-034 |

**TU-2 の作り方**: `Board.Tutorial()` が返す固定盤面で、
`sleep_pretend` の 1 回目が**必ず成功する**ように用途の通番を選ぶ。
（成功率は `Tuning` だが、固定盤面の seed 側で当たりを引かせる）
