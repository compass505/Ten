# MOD-End — 終了条件

種別: リファレンス / 層: **純粋層**
更新トリガー: 終わり方が増減したとき / 判定順を変えたとき
対応要件: REQ-007 / 018 / 042 / 047 / 050 / 051

## 公開 IF

```csharp
public static class NightEnd {
    /// 終了していれば EndKind、していなければ null。**MOD-Score の後に呼ぶ**（REQ-051）
    public static EndKind? Evaluate(NightState s, Tuning tuning);
}
```

## 判定順（固定。同 tick に複数成立したときの一意性）

| 順 | 終わり方 | 条件 | 要件 |
| --- | --- | --- | --- |
| 1 | `Dawn` | `Tick >= 5400` | REQ-007 |
| 2 | `FellAsleep` | `FallAsleep` または `DozeOff` が成立している | REQ-018 / 047 |
| 3 | `HandEmpty` | `Hand.Total == 0` かつ `Parent != Caring` | REQ-042 / 050 |

**この順で先に成立したものを記録する**（REQ-054 の表示が一意に決まる）。

## 満たすこと

| # | 性質 | 要件 |
| --- | --- | --- |
| E-1 | **`MOD-Score` の後に評価される。**最後の 1 枚の得点は終了判定より先 | REQ-051 |
| E-2 | 山札 0 は、対処による消費か出来事による減少かを問わず終了 | REQ-050 |
| E-3 | 対処の途中（`Caring`）で山札が 0 になっても、**その対処が終わるまで夜は終わらない** | REQ-042 |
| E-4 | 一度 `Over` が付いたら変わらない | — |

**E-1 の反例テスト**: 山札 1 枚の状態で最後の対処が終わり、その上昇で覚醒度が 100 に達する入力列。
**得点が 1 増えたうえで `HandEmpty` になる**こと。逆順だと得点が入らない。

## エラー時

| 状況 | 振る舞い |
| --- | --- |
| `s.Tick > 5400` | `Dawn` を返す（**例外にしない**。復元時に境界を跨ぐことがある） |
