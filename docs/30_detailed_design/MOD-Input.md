# MOD-Input — タッチ → 入力イベント

種別: リファレンス / 層: **境界層**
更新トリガー: 操作が増減したとき / 量子化の規則を変えたとき
対応要件: REQ-002 / 003 / 005 / 038 / 039 / 059

## 公開 IF

```csharp
public interface IInputSource {
    /// この tick に割り付いた入力。**1 tick 1 件に正規化済み**
    TickInput Sample(int tick);
    /// 首の向き（表示層だけが使う。状態列に影響しない）
    (float YawDeg, float PitchDeg) Look { get; }
}

public sealed class TouchInput : IInputSource { }
public sealed class TraceInput : IInputSource { }   // 入力列を再生（ハーネス）
```

## 満たすこと

| # | 性質 | 要件 |
| --- | --- | --- |
| IN-1 | **1 tick 1 件に正規化する。**同じ tick に複数来たら先着 1 件を採り、残りは捨てる | REQ-039 |
| IN-2 | 捨てた入力は**キューに残さず、副作用も起こさない** | REQ-059 |
| IN-3 | 首振りのドラッグ中でも行動を受け付ける | REQ-038 |
| IN-4 | 同じ行動を連打しても二重に発火しない | REQ-038 |
| IN-5 | **2 か所以上の同時接触を要求しない。**行動の操作対象は画面の下半分 | REQ-005 |
| IN-6 | 首振りの角度は左右 ±55°、上下 −15°〜+30° に丸める | REQ-002 / setting.md 3 節 |
| IN-7 | `TraceInput` に差し替えられる | ADR-0002 D3 |
| IN-8 | **最初のドラッグまでは、注入した初期視線を向く。**首振りは**ドラッグの相対量**で動く（触れただけで跳ばない。持ち替えても向きが残る）。TC-178 / 179 | REQ-002 / screens.md 4.2.1 |

**`Look` は状態列に入らない**（[data_model.md](../20_basic_design/data_model.md) 5 節）。
純粋層に渡さないことで、機械的に保証する。

## エラー時

| 状況 | 振る舞い |
| --- | --- |
| ポインタが画面外で離された | 押しっぱなしを解除する（押しっぱなしが残り続けない） |
| 複数指 | **最初の 1 本だけを見る。**2 本目以降は無視 |
